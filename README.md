# Arquitectura del proyecto

La aplicación sigue una arquitectura frontend modular orientada a componentes visuales y colaboración dinámica.

```text
┌──────────────────────────────┐
│          HTML UI             │ ← Interfaz principal
├──────────────────────────────┤
│            SCSS              │ ← Estilos modulares
├──────────────────────────────┤
│        JavaScript            │ ← Interactividad
├──────────────────────────────┤
│      DOM Manipulation        │ ← Eventos dinámicos
├──────────────────────────────┤
│      Component System        │ ← UI reutilizable
└──────────────────────────────┘
```
